# AoTTG2-Prolonpo
AoTTG2 with a Prolonpo flair! Features and content ahead of the base game!

Note that this repo serves to store builds as they are built and released.

# Download link
Download this version to start: https://github.com/Prolonpo/AoTTG2-Prolonpo/releases/download/V.1.5-base-AoTTG2-Prolonpo-with-autoupdater/AoTTG2-Prolonpo.Build.zip

It will contain an auto-updater, the game will tell you if the game is outdated and if you give it permission, it will proceed to download, extract, and update the game automatically.
