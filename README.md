# AoTTG2-Prolonpo
AoTTG2 with a Prolonpo flair! Features and content ahead of the base game!

Note that this repo serves to store builds as they are built and released.

# Download link
Download this version to start: https://github.com/Prolonpo/AoTTG2-Prolonpo/releases/download/V.9.0.3/Aottg2-Prolonpo_Data.zip

It contains an auto-updater, the game will tell you if it is outdated. If you give permission, the auto-downloader will proceed to download, extract, and update the game automatically.
